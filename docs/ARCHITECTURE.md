# Устройство приложения
Roomlet — одно приложение Next.js App Router с TypeScript. Группа маршрутов src/app/(store) несёт общую навигацию магазина. Серверные страницы src/app/studio проверяют демо-сессию до передачи расписания. /design-system отображает интерактивные образцы. В системе путей @/ соответствует src/.

| Область | Ответственность |
| --- | --- |
| src/features/store | Данные четырёх моделей, независимые способы изготовления и продажи, поиск, галерея, избранное, корзина, локальная заявка |
| src/features/booking | Чистые функции календарных вычислений, публичные статусы и выбор окна |
| src/features/studio | Серверные данные расписания, подписанная демо-сессия и экраны мастера |
| src/components, src/styles | Базовые элементы, составные компоненты, токены и адаптивные стили |
| src/lib/analytics.ts | Типизированный интерфейс события и локальный адаптер |
| tests, e2e | Проверки правил и сценарии браузера |

Сервер получает данные изделия по slug. Неизвестный slug возвращает 404. Избранное, корзина и черновики сохраняются в браузере. Фото и шрифты включены в приложение. Перезагрузка сервера создаёт новый ключ подписи cookie демовхода. В production понадобится управляемая аутентификация мастера, постоянная база, контроль прав и проверка запросов на стороне сервера. Демо-вход открыт любому посетителю и пригоден только для учебных данных.

Версии сверены до установки по актуальным engine/peerDependencies в npm и зафиксированы в package-lock.json. Сборка использует Next.js 16, React 19, Tailwind 4, Lucide и TypeScript 5.9. Для миниатюр, запросов и событий достаточно встроенных возможностей среды. Привязка к Telegram, PostHog, Supabase Auth/Storage и платежам отложена до соответствующих этапов.
