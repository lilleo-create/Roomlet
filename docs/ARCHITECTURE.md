# Архитектура
Next.js App Router и TypeScript обслуживают Store и Studio. Общие токены, компоненты и кириллические шрифты сохранены с Phase 01. Настройки подключения читаются сервером из переменных окружения.

| Область | Реализация |
| --- | --- |
| Публичный каталог | src/features/store/catalog-data.ts запрашивает roomlet_catalog от имени anon даже при активной сессии мастера. Каталог, карточка и прокси фотографий читают актуальное состояние |
| Авторизация Studio | Supabase Auth по email/password, SSR cookies, обновление сессии для /studio в src/proxy.ts. requireStaff проверяет пользователя через Auth и роль profiles перед чтением или записью |
| Изделия | src/features/inventory и маршруты /studio/products. Обновление модели, количества готовых экземпляров, условий предложения, себестоимости и связей фотографий объединено в транзакцию |
| Медиа | Приватный bucket product-media. Studio оптимизирует фото для загрузки, сервер проверяет содержимое и сохраняет WebP. Публичный путь работает через anon и правила видимости опубликованных карточек |
| График | Studio читает приватные таблицы, а витрина получает проекцию доступности через /api/availability |
| Будущие модули | Структура заказов, запросов, производственных работ, обновлений, аналитики и контентных черновиков включена в миграцию. Бизнес-процессы будут добавляться отдельно |

Справочник ролей, ограничения денег и источник прав описаны в SCHEMA.md. Ознакомьтесь с SETUP.md перед применением миграции. История демонстрации и старые скриншоты сохранены в VERIFICATION.md.
