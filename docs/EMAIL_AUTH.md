# Почтовая авторизация Roomlet

Roomlet использует стандартные шаблоны и доставку Supabase для подтверждения регистрации и восстановления пароля. Внешний SMTP, домен и фирменные шаблоны для этого этапа не требуются.

Для регистрации достаточно email и пароля. Имя необязательно. Пока адрес не подтверждён, пользователь видит экран «Проверьте почту». Стандартное письмо содержит ссылку. Откройте её в том же браузере, подтвердите адрес на странице Roomlet и продолжите с выбранного раздела. Для повторной отправки предусмотрена пауза 60 секунд. Ссылка «Запросить письмо подтверждения» доступна со страницы входа. Права покупателя назначаются существующей серверной логикой.

Восстановление начинается на странице «Забыли пароль?». Roomlet отвечает одинаково для зарегистрированного и неизвестного адреса. Ссылка из стандартного письма открывает ввод нового пароля. Обмен PKCE выполняется на сервере в отдельной сессии восстановления. Смена пароля требует подтверждённой recovery-операции. После успеха временная сессия закрывается, и пользователь входит заново. Ошибки ссылки и истёкшего кода показаны на русском.

## Рабочий проект

Встроенный SMTP Supabase доставляет почту только на адреса участников команды организации. Текущий общий лимит проекта — два письма в час. Публичная регистрация произвольных покупателей через такую доставку ограничена. Перед переходом на HTTPS отдельно согласуются Site URL и список разрешённых обратных адресов. Параметры рабочей базы и шаблоны писем в Issue #3 не менялись.

Во время проверки владелец подтвердил получение стандартного письма восстановления на разрешённый адрес. Изменение пароля и проверка новой регистрации выполняются только на отдельной тестовой учётной записи локального предпросмотра.

## Локальная проверка

На порту 3211 подтверждение email включено. Стандартные письма Supabase Lite попадают в локальную консоль. Три предсозданных демоаккаунта имеют подтверждённые адреса. При остановленном демосервере выполните `npm run demo:build`, затем `node tests/integration/email-preview.mjs`. Для интерактивного просмотра используйте `npm run demo:dev`.
