# Вход по почте

Формы магазина используют Supabase Auth и серверные cookies из `@supabase/ssr`. Каталог и карточки открываются гостям. Текущие пользователи входят с прежними UUID и паролями. Вход в Studio дополнительно проверяет роль из `profiles`.

## Создание аккаунта

Для регистрации нужны почта и пароль. Имя можно добавить сразу или в настройках профиля. В запросе регистрации приложение передаёт только `display_name` из разрешённых метаданных. При создании записи триггер в базе назначает `customer`. После получения сессии сервер переносит имя в пустое поле собственного профиля. Формы регистрации не запрашивают телефон, адрес доставки или рекламное согласие.

Если в Supabase включено подтверждение адреса, пользователь получает письмо. В том же браузере он может завершить PKCE-переход из письма. При шаблоне с одноразовым кодом пользователь также может ввести код и адрес на странице подтверждения. Когда подтверждение отключено, Supabase сразу создаёт сессию. В обоих случаях пользователь возвращается в разрешённый раздел магазина.

## Восстановление

Форма «Забыли пароль?» вызывает `resetPasswordForEmail`. Сообщение после запроса одинаково для новых и зарегистрированных адресов. Ссылка из письма открывает установку нового пароля. Второй способ — ввести полученный код и адрес. Проверка и смена выполняются в отдельной сессии восстановления. После успеха эта сессия закрывается, пользователь входит с новым паролем. Выбранная коллекция или раздел профиля сохраняются при переходе.

## Настройка Supabase Auth

1. Задайте `ROOMLET_SITE_URL` равным полному HTTPS-адресу магазина. Для локального запуска приложение распознаёт localhost. Адрес из произвольного заголовка Host не используется как адрес письма.
2. Установите Site URL и разрешите обратные адреса магазина `/profile/confirm` и `/profile/recover`, в том числе их варианты с query-параметром `next`. Используйте свой точный домен. У нестандартных шаблонов письма ссылка должна сохранять перенаправление Supabase с кодом PKCE.
3. В шаблонах **Confirm signup** и **Reset password** оставьте стандартную ссылку `{{ .ConfirmationURL }}`. Для входа по коду добавьте `{{ .Token }}`. Для рабочей рассылки используйте настроенную доставку почты в Supabase.
4. На изолированном порту 3211 Supabase Lite подтверждает адрес сразу при регистрации. Код восстановления из локального письма доступен в консоли процесса `npm run demo:dev`. Почта на внешние адреса из демосреды не доставляется.
