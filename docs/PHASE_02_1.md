# Roomlet · Проверка Phase 02.1

Демонстрационная витрина работает на порту 3211 с отдельным локальным Supabase Lite. Страницы обычного магазина на порту 3000 продолжают читать подключённый проект Supabase. При проверке его публичный каталог был пуст. [Открыть демокаталог](http://127.0.0.1:3211/catalog) · [Открыть Studio](http://127.0.0.1:3211/studio).

## Браузерные проверки

Во внутреннем браузере Codex пройдены 23 страницы и состояния на ширинах 320, 360, 390, 430, 768 и 1440 CSS-пикселей. Измерения ширины документа показали нулевое горизонтальное переполнение во всех 138 сочетаниях. На каждом размере получен снимок окна. В репозитории сохранены 5 исходных и 48 итоговых снимков, включая дополнительные состояния. Проверки относятся к браузерным размерам окон. На физическом Samsung и внутри клиента Telegram прогон ещё не выполнялся.

| Раздел | Проверенные страницы и действия |
| --- | --- |
| Store | Главная, каталог, четыре карточки, избранное, профиль, корзина и индивидуальный проект. Проверены карусель, поиск с разным регистром, фильтр, сохранение избранного после перезагрузки, переключение восьми изображений, увеличение и закрытие через Escape. |

| Studio | Вход через Supabase Auth, главный экран, календарь, заказы, настройки, список, создание и редактирование изделия. Временная карточка с загруженным WebP прошла через черновик, публикацию, архив и удаление. Store отразил изменение цены библиотеки с 6 500 на 6 501 ₽ и обратное сохранение. |

```powershell
$demo = Get-Content -Raw .roomlet-demo/credentials.json | ConvertFrom-Json
$env:ROOMLET_LOCAL_MAKER_EMAIL = $demo.email
$env:ROOMLET_LOCAL_MAKER_PASSWORD = $demo.password

$env:NEXT_PUBLIC_SUPABASE_URL = 'http://127.0.0.1:54331'
npm run test:e2e
```

## Удаление демонстрационных изделий

В корне Roomlet выполните `npm run demo:clean`. Команда удаляет помеченные образцы и их файлы из локального Storage. Категория сохраняется, если на неё ссылается другое изделие. Повторная очистка безопасна. После перезапуска витрина останется пустой. Команда `npm run demo:seed` восстановит четыре образца с восемью изображениями. На существующих образцах повторный seed сохраняет изменения мастера. [Запуск и данные для входа](../README.md#локальный-демонстрационный-каталог).
