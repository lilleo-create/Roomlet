# Доступность мастерской
Источник истины для часового пояса, резерва, недельного графика и блокировок — workshop_settings, working_hours и blocked_periods в Supabase. В настройках мастер задаёт доступные часы для каждого из семи дней. Ноль означает выходной. После вычета ежедневного резерва доступные минуты не могут стать отрицательными. Блокировка закрывает обе граничные даты и все дни между ними.

Внутренний календарь Studio показывает даты и причины блокировок после проверки роли. Покупатель получает из roomlet_availability дату и доступные минуты, без причин, заказов и финансов. Горизонт расчёта — 70 следующих дней по часовому поясу мастерской. В интерфейсе сохранён предварительный просмотр окна из двух смежных доступных дней. Просмотр не создаёт резерв. Полноценный серверный Booking с длительностью по трудозатратам, защитой от конфликтов, сроками резервов и подтверждением мастером относится к следующему этапу.
