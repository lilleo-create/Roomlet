Неопределённый результат сетевого запроса может оставить невостребованный файл. [Порядок проверки и очистки](INVENTORY.md).

## Локальная коллекция Phase 02.1

`npm run demo:dev` собирает приложение в `.roomlet-demo/build/` и запускает [Store](http://127.0.0.1:3211/) и [Studio](http://127.0.0.1:3211/studio) с отдельной базой Supabase Lite. Ключи и пароль локального мастера создаются при первом запуске. Для просмотра почты и пароля выполните команду из [инструкции по запуску](../README.md#локальный-демонстрационный-каталог).

| Изделие | Цена | Доступность |
| --- | ---: | --- |
| Ночная библиотека | 6 500 ₽ | Готовый экземпляр |
| Токийское кафе | 5 900 ₽ | Изготовление под заказ |
| Оранжерея | 7 900 ₽ | Предстоящий выпуск |
| Ателье художника | 8 500 ₽ | Экземпляр продан |

Локальный демокаталог можно очистить командой `npm run demo:clean`, а затем восстановить через `npm run demo:seed`. Предпросмотр сохраняет результат очистки при перезапуске. [Удаление и восстановление примеров](../README.md#удаление-и-восстановление-примеров).
