# Аналитика
Функция track(event, properties) в src/lib/analytics.ts типизирует имена событий. Демонстрационный адаптер посылает CustomEvent «roomlet:analytics» текущему окну браузера. Подписчик получает event, properties и timestamp. Журнал для отладки можно включить из DevTools:

```js
window.addEventListener("roomlet:analytics", ({ detail }) => console.log(detail));
```

Экраны магазина регистрируют просмотры, поиск и выбор фильтра, действия с избранным, просмотр деталей, добавление в корзину и этапы локальной заявки. Календарь регистрирует показ, выбор и потерю доступности. Значение поисковой строки, контактные данные и текст индивидуальной заявки не входят в параметры событий. При сохранении демонстрационного заказа отправляется order_created с demo=true. Событие purchase зарезервировано для подтверждённого факта оплаты.

Полный утверждённый словарь и планируемые метрики приведены в §11 PRODUCT.md. PostHog, атрибуция публикаций, доходность, производственные показатели и отчёты отложены. Для их подключения потребуется адаптер доставки, политика согласия и серверный источник подтверждения бизнес-событий.
