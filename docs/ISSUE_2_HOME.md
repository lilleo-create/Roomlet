## Проверки

- Карусель читает весь опубликованный каталог через существующую RPC с пагинацией. Готовые и заказные работы стоят в начале. В DOM по одной карточке на запись. При возврате из изделия восстанавливается его UUID в пределах вкладки.
- Во внутреннем браузере на 390 px проверены переход клавишей влево с первой на последнюю работу и обратно, горизонтальное перетаскивание по фотографии, открытие «Токийского кафе» и восстановление позиции после возврата. На всех шести ширинах документ поместился по горизонтали.
- Отдельная HTTP-проверка production-сборки охватывает пустой каталог, 1, 2 и 105 публичных записей, скрытые демоданные и отказ сервиса. В набор Playwright добавлены проверки циклической границы, сенсорного жеста Chromium и возврата к изделию. Физический телефон в этом прогоне не использовался.
- Прошли ESLint, TypeScript, 28 модульных и PostgreSQL-тестов, HTTP-интеграция, production build и локальная демосборка.
- В исходном отчёте Playwright прошли 25 из 26 без пропусков. При отключённом JavaScript Chrome отправлял форму входа с `Origin: null`, и Next.js вернул 500. На страницах почтовой авторизации установлена политика `strict-origin`, передающая origin без пути и параметров. Проверка origin в Next.js сохранена.
- Полный повтор запускается из корня Roomlet командой `.\supabase\demo\test-e2e.ps1` в обычном PowerShell. В изолированной оболочке Codex Windows отклонила создание рабочего процесса Playwright до первого сценария.
