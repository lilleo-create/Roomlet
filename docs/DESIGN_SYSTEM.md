# Дизайн-система 1.0
Утверждённые значения палитры, размеров и движения приведены в §6 PRODUCT.md. Реализация — src/styles/tokens.css, src/styles/ui.css, src/components/ui.tsx, src/components/patterns.tsx и компоненты сценариев в src/features. Страница /design-system показывает элементы в рабочем состоянии.

Галерея сочетает контрастный текст с музейными фотографиями и лаконичной экспликацией. Manrope Variable используется для заголовков, Golos Text Variable — для набора. Шрифты с кириллицей включены в сборку. Мобильный экран использует поля 20 px, кнопки от 52 px, нижнюю навигацию с safe-area. Пользовательская настройка reduced motion отключает необязательные переходы.

Контраст текста на Canvas (WCAG): Ink 16,35:1, Muted 4,68:1, Success 4,75:1, Warning 4,65:1, Error 4,99:1. Белый на Primary — 5,12:1. Для Signal подходит тёмный текст (5,93:1); отдельный мелкий текст цвета Signal на Canvas даёт только 2,76:1. Border предназначен для декоративных разделителей. Проверяйте режимы фокуса с клавиатуры, активное, пустое и недоступное состояния в /design-system.
