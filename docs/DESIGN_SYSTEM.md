# Дизайн-система Roomlet
Утверждённые значения палитры, размеров и движения приведены в §6 PRODUCT.md. Реализация — src/styles/tokens.css, src/styles/ui.css, src/components/ui.tsx, src/components/patterns.tsx и компоненты сценариев в src/features. Библиотека компонентов на `/design-system` доступна сотрудникам после входа.

Галерея сочетает крупные фотографии миниатюр с короткими подписями. Manrope Variable используется для заголовков, Golos Text Variable — для набора. Шрифты с кириллицей включены в сборку. Мобильный экран использует поля 20 px, кнопки от 52 px, нижнюю навигацию с safe-area. Пользовательская настройка reduced motion отключает необязательные переходы.

Контраст текста на Canvas (WCAG): Ink 16,35:1, Muted 4,68:1, Success 4,75:1, Warning 4,65:1, Error 4,99:1. Белый на Primary — 5,12:1. Для Signal подходит тёмный текст (5,93:1); отдельный мелкий текст цвета Signal на Canvas даёт только 2,76:1. Border предназначен для декоративных разделителей. Проверяйте режимы фокуса с клавиатуры, активное, пустое и недоступное состояния в /design-system.

## Профиль и состояния коллекции

Профиль использует шапку Store и один заголовок «Мой профиль». За блоком аккаунта идут доступные пользователю разделы. Кобальтовая карточка Studio предназначена для мастера и владельца. Только владелец видит управление командой. В вертикальном меню предусмотрены контурные иконки, тонкие разделители, строки от 64 px и видимый фокус клавиатуры.

`PageHeading` задаёт адаптивный заголовок, описание и необязательное действие. От заголовка до описания остаётся 12–16 px, до следующего блока — 20–24 px. Между секциями оставляют 32–40 px. Для кириллицы используются Manrope с межбуквенным интервалом −0,035 em в заголовке и Golos Text с обычным интервалом в основном тексте.

`EmptyState` располагается на фоне Canvas. В зависимости от раздела используется контурная иконка размером 64–80 px, короткий заголовок и пояснение. Действие ведёт к доступному следующему шагу, например к каталогу из избранного или к сбросу фильтров поиска. Ошибка API отображается через `ErrorState` с повтором запроса, загрузка — через `Skeleton`. Обложки изделий сохраняют пропорцию 4:3, а статусы и цены используют общие строки сетки карточек.
