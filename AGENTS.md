# Roomlet
Текущий этап — Phase 02.1, рабочая ветка feature/backend-studio, основа 49bea5b. Сохраняйте утверждённые дизайн-токены, русскоязычный интерфейс и адаптацию от 320 px. Слияние в main требует отдельного утверждения.

- Пользовательский каталог читает roomlet_catalog с анонимным publishable-клиентом, даже если посетитель вошёл как мастер.
- Все приватные страницы и записи Studio проверяют подтверждённого пользователя и роль из profiles. RLS и привилегии PostgreSQL защищают данные при прямом обращении к API.
- Деньги храните целыми единицами младшего разряда с кодом валюты. Загрузки проходят через приватный Storage. Даты мастерской вычисляйте по её сохранённому часовому поясу.
- Четыре демонстрационных изделия и фотографии загружайте через локальный seed в отдельный Supabase. Команда `npm run demo:dev` запускает предпросмотр на 127.0.0.1:3211. Для интеграционных проверок записей используйте отдельную локальную базу и тестовые аккаунты.
- Проверки, настройка, ограничения и границы этапа перечислены в README.md и docs/SETUP.md.

## Рабочая папка и локальный запуск

На этом компьютере основной каталог проекта — `%USERPROFILE%\Desktop\Frontend\Roomlet`. В PowerShell откройте его командой `Set-Location -LiteralPath "$env:USERPROFILE\Desktop\Frontend\Roomlet"`. Выполняйте изменения, команды Git и npm, тестирование, миграции и запуск непосредственно из корня этого репозитория. Для следующих этапов продолжайте работу в этой папке.

Запускайте Store и Studio одной командой `npm run dev`. После каждого этапа проверьте магазин по адресу `http://localhost:3000/` и Studio по адресу `http://localhost:3000/studio`. Если dev-сервер уже запущен из этого каталога, используйте его повторно. Перед установкой пакетов проверяйте свободное место на C:.
