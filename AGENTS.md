# Roomlet
Текущий этап — Phase 02, рабочая ветка feature/backend-studio, основа 49bea5b. Сохраняйте утверждённые дизайн-токены, русскоязычный интерфейс и адаптацию от 320 px. Слияние в main требует отдельного утверждения.

- Пользовательский каталог читает roomlet_catalog с анонимным publishable-клиентом, даже если посетитель вошёл как мастер.
- Все приватные страницы и записи Studio проверяют подтверждённого пользователя и роль из profiles. RLS и привилегии PostgreSQL защищают данные при прямом обращении к API.
- Деньги храните целыми единицами младшего разряда с кодом валюты. Загрузки проходят через приватный Storage. Даты мастерской вычисляйте по её сохранённому часовому поясу.
- Музейные фотографии и локальные заявки допустимы только в явно включённой демонстрации. Для интеграционных проверок записей используйте отдельную локальную базу и тестовые аккаунты.
- Проверки, настройка, ограничения и границы этапа перечислены в README.md и docs/SETUP.md.
