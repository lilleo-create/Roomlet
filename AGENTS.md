# Работа с Roomlet
Спецификация и границы этапа находятся в docs/PRODUCT.md и docs/ROADMAP.md. Основной язык интерфейса — русский. Один Next.js-проект объединяет Store, Studio и правила календаря.
- Держите данные каталога и правила доступности отдельно от компонентов.
- Используйте общие дизайн-токены, семантические HTML-элементы и подписи на русском для иконок.
- Покупателю передавайте только доступность. Детали рабочего расписания выдаёт сервер после демовхода.
- Phase 01 работает на локальных данных. Настоящие интеграции и следующий этап требуют отдельного утверждения.
- Перед сдачей запустите npm run lint, npm run typecheck, npm test, npm run build и npm run test:e2e. Проверьте 320, 360, 390, 430 px и desktop.
- Рабочая ветка — feature/foundation. Слияние в main требует отдельного утверждения.
