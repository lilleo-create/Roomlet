# Roomlet · Phase 01
Мобильная галерея интерьерных миниатюр и рабочий календарь мастерской. В одной карточке можно выбрать готовый экземпляр или изготовление, посмотреть доступные даты и сохранить пробную заявку. Для проверки изменений доступности откройте Studio в соседней вкладке того же браузера.

## Запуск
Проверено с Node.js 22.21.1 и npm 11.6.2. Требуется Node.js от 22.13. Из корня проекта:

```sh
npm ci
npm run dev
```

Откройте [магазин](http://localhost:3000), [Studio](http://localhost:3000/studio) или [дизайн-систему](http://localhost:3000/design-system). Для Studio нажмите **Открыть демо**. Настройка окружения для запуска не требуется.

## Что посмотреть
- `/` и `/catalog` — коллекция, поиск по названию или номеру, фильтры по категории и доступности.
- `/product/atelier` — библиотека-ротонда с двумя способами заказа, галереей и выбором предварительного окна.
- `/favorites`, `/cart`, `/profile` и `/custom` — сохранённые объекты, пробное оформление и локальные черновики.
- `/studio` — план дня, ближайший срок и заявки. `/studio/calendar` — выбор даты, неделя/месяц и локальная блокировка. Заказы и изделия в Studio доступны для просмотра.
- `/design-system` — токены и интерактивные образцы компонентов.

## Проверки
```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

На Windows браузерные тесты используют установленный Google Chrome. Для Linux и macOS установите Chromium через `npx playwright install chromium`. Playwright поднимает production-сервер на порту 3210. Если он уже запущен локально, тесты используют его. Для локального просмотра production-сборки выполните `npm start`.
Для обновления скриншотов задайте переменную `ROOMLET_SCREENSHOTS=1` при запуске браузерных тестов. Ширины проверки — 320, 360, 390, 430 и 1366 px.

## Данные и ограничения
Каталог иллюстрируют четыре музейные миниатюры из коллекции Thorne. Цены, наличие, некоторые характеристики и производственные сроки заданы для демонстрации. Источники и лицензии приведены в [описании фотографий](docs/IMAGES.md).

Магазин хранит заявки в этом браузере. Они не передаются мастеру. Строка контакта остаётся в форме. Окно означает предварительную доступность на два дня и не даёт межпользовательской гарантии бронирования. Изменения блокировок видны вкладкам одного origin. Демо-вход Studio предоставляет доступ к учебному расписанию на восемь часов. Платежи, база Supabase, внешние события аналитики, реальная отправка сообщений и AI-сервисы не подключены.
